# @sakibcoolz/components

Industrial component catalog for `@sakibcoolz/core`: tanks (vertical, conical, horizontal, spherical, pool), pipes, ASME B16.9 fittings, B16.10 ball valves, pumps, with ports, bounds and framework-free geometry parts. Dimensions follow common ASME tables; verify before engineering use.

```sh
npm install @sakibcoolz/components
```

```ts
import { catalogResolvers, componentCatalog } from '@sakibcoolz/components';
```

Part of the [3D SCADA SDK](https://github.com/sakibcoolz/3d-scada-sdk). API reference: [docs/API.md](https://github.com/sakibcoolz/3d-scada-sdk/blob/develop/docs/API.md). ESM only, Node.js 20+.

The SDK visualises and simulates; it does not connect to or control PLCs or physical equipment.
