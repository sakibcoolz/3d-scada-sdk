Industrial 3D SCADA and HMI screens for the web, in Three.js and React

3D SCADA SDK is an open-source TypeScript toolkit for drawing process plants in the browser: tanks, pumps, valves and ASME piping joined by a typed port graph, a React Three Fiber editor and viewer, 2D P&ID and electrical views of the same scene, and a locked operator runtime that shows your live values and alarms.

What it does

Process equipment and piping

A procedural catalog of 14 kinds (tanks, pumps, valves, elbows, tees, reducers, pipes) with dimensions based on common ASME tables, plus your own namespaced component types.

Typed port graph

Connections join named ports in five domains (fluid, mechanical, power, signal, network). Snapping, pipe routing and open-joint checks keep the model consistent.

3D editor and viewer

React components for viewing and editing a plant: undo and redo, import and export, glass, X-ray and cutaway views, walk mode and WebXR.

2D P&ID and electrical views

SVG process and electrical diagrams generated from the same scene, with automatic placement, saved layouts and one shared selection across 3D and 2D.

Locked operator runtime

ScadaRuntime shows an approved revision pinned by SHA-256 digest, with host alarms and value quality per component, and raises confirmed command requests to your application.

Acquisition description

Data sources and runtime variables with typed Modbus and OPC UA addresses, for your gateway to read. Transport examples for REST polling, Server-Sent Events and WebSocket.

Quick start

npm install @sakibcoolz/react @sakibcoolz/core @sakibcoolz/components three @react-three/fiber @react-three/drei react react-dom
import { useState } from 'react';
import { parseScene, type ScadaScene } from '@sakibcoolz/core';
import { catalogResolvers } from '@sakibcoolz/components';
import { Scada3DEditor, Scada3DViewer } from '@sakibcoolz/react';

const loaded = parseScene(savedJson, catalogResolvers); // savedJson: your scene file text
if (!loaded.ok) throw new Error(loaded.errors[0].message);

export function Plant() {
  const [scene, setScene] = useState<ScadaScene>(loaded.scene);
  const [editing, setEditing] = useState(false);
  return (
    <div style={{ height: '100vh' }}>
      <button onClick={() => setEditing(!editing)}>{editing ? 'View' : 'Edit'}</button>
      {editing
        ? <Scada3DEditor initialScene={scene} onChange={setScene} />
        : <Scada3DViewer scene={scene} viewMode="glass" />}
    </div>
  );
}

React 19, ESM only, Node.js 20+, TypeScript types included. See the React package guide and the runtime integration guide.

FAQ

Does the SDK connect to PLCs?
No. It never opens a network connection or writes to a device. Your application supplies values (from your gateway, historian or broker) and receives command requests, which it decides how to handle.
Which protocols does it understand?
A scene can describe Modbus and OPC UA addresses for each variable, so your gateway knows what to read. Transport is up to you; examples for REST, Server-Sent Events and WebSocket are included.
Can I use my own equipment models?
Yes. Register namespaced host component types with their ports and parameters, and draw them in 3D and as 2D symbols.
Is it a certified engineering tool?
No. Dimensions follow common ASME tables and must be verified before engineering use.
